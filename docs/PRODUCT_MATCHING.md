# Матчинг номенклатуры 1С

Принят по указанию пользователя 30.10.2026, с резервным прежним поиском.

1. Подтверждённые связи и явный выбор оператора сохраняют приоритет.
2. Для поиска кандидатов вызывается `App/invoicing/product_matcher.py`.
   Он ранжирует признаки типа и назначения товара, учитывает разные формы
   слов и сравнивает числа вместе с единицами. Это текстовый алгоритм,
   не нейронная модель; его оценка не является вероятностью соответствия.
3. Если список кандидатов пуст, вызывается неизменённый
   `default_search_catalog` — прежняя реализация поиска. Результаты помечены
   `match_method=default_fallback`; у нового алгоритма — `product_matcher_v1`.
4. Автоматические предложения остаются жёлтыми в PDF и не записываются как
   подтверждённые. Отсутствующее название 1С остаётся пустым и красным.
   Сам факт поиска не меняет коэффициенты, количества и суммы.

На примере «Кабель Нагревающийся Красный (100 м в бухте)» первыми теперь идут
нагревательные кабели вместо стяжек. Отличающаяся длина требует проверки
оператором; рейтинг не доказывает взаимозаменяемость.

Резервный поиск намеренно сохраняет и слабые результаты прежнего алгоритма:
для «Отбойник TEXA T26501» он возвращает «Триммер Бензиновый TEXA» с оценкой
41,9. Это результат резервного поиска, не подтверждённое соответствие;
По последующему прямому указанию пользователя порог 70 отменён: если
кандидаты найдены, лучший используется как жёлтое предложение независимо
от рейтинга. Это относится и к резервному поиску. Оператор может заменить
его вручную; подтверждённым такое предложение автоматически не становится.

Проверки: 6 новых интеграционных тестов матчинга; общий `App/tests` —
234 passed, 12 прежних failures отсутствующих исторических fixtures.
Сценарий Edge (выбор, замена, сохранение, перезагрузка, PDF, обучение на
изолированных данных) прошёл. Тест обновлён, чтобы дождаться завершения
поискового запроса перед выбором — иначе мог нажимать старый вариант.

## Резервное ИИ-сопоставление Торгсофт → 1С

После поиска по названию (новый алгоритм, затем прежний резервный поиск),
если кандидатов нет, читаются CSV из `data/reference/AI_matching`.
Товар Торгсофт определяется по нормализованному точному имени или артикулу.
Код основного кандидата и альтернатив разрешается в актуальном справочнике
1С; отсутствующие и неоднозначные коды пропускаются. Из доступных вариантов
используется лучший по оценке CSV. Результат — жёлтое неподтверждённое
предложение, доступное для ручной замены, а не обученное соответствие.
Оценка CSV не является проверенной вероятностью правильности.

Поддерживается фактический CSV с 22 колонками и прежние названия колонок
из README. Загружены 24 722 строки. Изменения CSV автоматически обновляют
кэш. Цены, остатки и отметки подтверждения CSV не используются для
ценообразования или автоматического подтверждения; цены берутся из чека.
Ручные и ранее подтверждённые соответствия сохраняют приоритет.

Проверка ИИ-резерва 30.10.2026: 34 целевых теста прошли, включая
формирование счёта/PDF без подтверждения и без изменения цены чека.
Общий набор: 262 passed, 12 прежних ошибок отсутствующих исторических
фотографий/артефактов. Лог: `data/eval/ai_matching_tests_20261030.log`.
Сервер обновлён после проверки отсутствия активных заданий.

В списке выбора показаны учётная цена 1С и цена единицы текущего чека.
Разница = abs(цена чека - цена 1С) / цена 1С * 100%, без пересчёта единиц
и НДС. Подписи: <50% Норма; 50–100% Внимание. Налог; >100%
БОЛЬШОЙ НАЛОГ ИПН!!!. Это заданные пользователем подписи, не расчёт налога.
При неизвестной/нулевой цене 1С процент не показывается.
